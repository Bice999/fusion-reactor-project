# **App Name**: TrustLink

## Core Features:

- Secure Partner Linking: Easy setup and connection between partners via a secure, shared code.
- Scheduled Check-in Prompts: Ability to set personalized check-in reminders throughout the day.
- One-Tap Confirmation: Quick, one-tap check-in to confirm location and activity.
- AI-Powered Response Suggestions: Smart Suggestions tool for appropriate check-in responses based on recent activities and location.
- Partner Status Dashboard: Real-time display of partner's status and recent check-ins.

## Style Guidelines:

- Primary color: Soft blue (#64B5F6) to evoke trust and tranquility.
- Background color: Very light blue (#E3F2FD), almost white, providing a clean backdrop.
- Accent color: Gentle green (#81C784) to signal positive confirmations and successful check-ins.
- Font: 'PT Sans' (sans-serif) for clear and accessible text throughout the app.
- Simple, friendly icons to represent different actions and statuses.
- Clean, card-based layout for easy scanning and interaction.
- Subtle animations for check-ins and status updates, providing smooth and reassuring feedback.
